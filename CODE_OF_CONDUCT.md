# Code of Conduct

This project follows the Contributor Covenant Code of Conduct.

## Our Standard

Project participants are expected to be respectful, constructive, and considerate of differing viewpoints and experience levels.

Unacceptable behavior includes harassment, intimidation, discriminatory language, or sustained disruption of project work.

## Enforcement

Instances of unacceptable behavior may be reported by opening a private security advisory or contacting the project maintainers through the repository owner profile.

Maintainers may remove comments, close issues, reject contributions, or restrict participation when needed to protect the project community.
