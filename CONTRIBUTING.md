# Contributing

Thanks for your interest in contributing.

## Development

```bash
npm test
```

## Pull Requests

Before opening a pull request:

1. Keep the change focused.
2. Add or update tests for behavior changes.
3. Run `npm test`.
4. Describe the user-facing impact in the pull request body.

## Issues

Please include:

1. What you expected to happen.
2. What actually happened.
3. A minimal example or reproduction steps when possible.
